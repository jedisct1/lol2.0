# LOL2.0-Double

A C implementation of the LOL2.0-Double stream cipher and its SCMAC AEAD mode.

LOL2.0-Double takes a 256-bit key and a 256-bit IV and produces keystream in 32-byte blocks.

Reference:  "SCMAC and LOL2.0: An AEAD Design Framework and A New Version of LOL Stream Cipher Design Framework" by Feng, Jiao, Hao, Zheng, Wu, Qi, Zhang, Zhang, Sun and Tian.
